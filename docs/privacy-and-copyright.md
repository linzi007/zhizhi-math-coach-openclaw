# Privacy And Copyright Boundary

## Public Repository

The public repository may include:

- reusable instructions;
- generators and validators;
- empty or sanitized templates;
- synthetic sample mistakes and worksheets;
- external source links.

The public repository must not include:

- real student names;
- real school names;
- school worksheet photos;
- completed paper photos;
- teacher feedback screenshots;
- textbook PDFs;
- textbook screenshots or scans;
- OCR dumps from textbooks;
- copied textbook problem sets.

## Private Learning Workspace

Private workspaces may contain student records and parent-provided textbook references. Keep them outside this repository or under ignored paths.

## Textbook Use

Use textbook references for scope:

- grade;
- semester;
- edition;
- volume;
- unit;
- knowledge point;
- page or source reference.

Generate original explanations and original practice problems. Do not copy textbook content into generated public examples.
