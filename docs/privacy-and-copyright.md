# Privacy And Copyright Boundary

## Public Repository

The public repository may include:

- reusable instructions;
- generators and validators;
- empty or sanitized templates;
- synthetic sample mistakes and worksheets;
- public child-facing worksheet HTML without answers or student identifiers;
- external source links.

The public repository must not include:

- real student names;
- real school names;
- school worksheet photos;
- completed paper photos;
- teacher feedback screenshots;
- textbook PDFs;
- textbook screenshots or scans;
- OCR dumps from textbooks;
- copied textbook problem sets.

## Public GitHub Pages

GitHub Pages may be used for child-facing worksheet HTML when public access is acceptable.

The Pages `site/` directory must not include:

- answer keys;
- grading or diagnosis records;
- memory files;
- weak-point history;
- real student names or school names;
- uploaded school papers or completed worksheet photos;
- textbook PDFs, screenshots, scans, or OCR output.

## Personal Learning Workspace

Personal learning workspaces may be public or private; the user chooses. They may contain student records and parent-provided textbook references, so keep them outside this reusable skill repository. If the personal repository is public, do not commit sensitive files, answers, memory, diagnosis history, uploads, or textbook-derived raw material.

## Textbook Use

Use textbook references for scope:

- grade;
- semester;
- edition;
- volume;
- unit;
- knowledge point;
- page or source reference.

Generate original explanations and original practice problems. Do not copy textbook content into generated public examples.
